# PutSiteAuthorRequest

The whole author: fields you leave out are removed. Links must be https URLs.

## Example Usage

```typescript
import { PutSiteAuthorRequest } from "@usenotra/sdk/models";

let value: PutSiteAuthorRequest = {
  name: "Jane Doe",
  title: "Head of Product",
  avatar: "/images/jane.png",
  x: "https://x.com/janedoe",
};
```
